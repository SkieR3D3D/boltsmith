Boltsmith — генератор кріплення -> STEP (справжня гвинтова різьба)
==================================================================

Ярлик з іконкою: один раз запустіть Create_Shortcut.bat — з'явиться «Boltsmith»
на робочому столі та в меню «Пуск» (запуск без чорного вікна консолі).
Запуск з консоллю (для діагностики): Fastener_Generator.bat
Мова перемикається у вікні (вгорі праворуч: «Мова / Language») і запам'ятовується.
(Fastener_Generator_EN.bat завжди відкриває англійською.)
Перший запуск завантажує CAD-ядро (кілька хвилин, один раз); далі — секунди.
Файли зберігаються в папку output\ поруч (можна змінити у вікні).

ВКЛАДКИ
- Болт / гвинт
  * Стандарт: 26 типів ISO/DIN з точними таблицями розмірів
    (циліндрична, напівкругла, потайна, напівпотайна, шестигранна, з фланцем,
     пан-головка; шестигранник / Torx / шліц / Phillips; установочні, плечові).
  * Власний: M1-M100, будь-який крок, головка (циліндрична, купол, потайна,
    напівпотайна, пан, шестигранна, з фланцем, без головки) + шліц
    (шестигранник, Torx, трикутник, квадрат, п'ятигранник, шліц, хрест).
    Можна задати довжину різьби та розміри головки вручну.
- Гайка
  * Стандарт: ISO 4032/4033/4035/4036, з фланцем DIN 1665, ковпачкова DIN 1587,
    квадратна DIN 557, термовставки для 3D-друку (McMaster, CNC Kitchen, ruthex, Hilitchi).
  * Власна: M1-M100 — шестигранна, низька, самоконтрівна з нейлоновим кільцем
    (ISO 7040, кільце окремим тілом), меблева гайка-втулка (плоска/потайна головка,
    будь-який шліц), подовжувальна DIN 6334.
- Шайба: ISO 7089/7090/7091/7092/7093/7094, зубчаста DIN 6797; власна плоска
  та пружинна (гровер DIN 127, справжня гвинтова форма).
- Шпилька: різьбовий пруток будь-якого розміру й довжини.
- Комплект: болт з першої вкладки + гайка + шайби, розставлені на задану
  товщину з'єднання — готовий вузол для збірки (кожна деталь окремим тілом).

ЗАГАЛЬНЕ
- Права / ліва різьба (LH) для всього.
- «Одне суцільне тіло»: різьба зливається з деталлю. Якщо ядро не змогло
  злити (рідко, напр. потайні Torx ISO 14581/14584), буде 2 тіла —
  у Fusion: Modify > Combine.
- «Також STL» — для друку.

ПРИМІТКИ
- Розміри «Власних» деталей рахуються за формулами, наближеними до ISO/DIN;
  для точних стандартних — використовуйте режим «Стандарт».
- Torx і Phillips у власних деталях — спрощена, але реалістична форма.
- Різьба без допусків посадки (номінальний профіль ISO). Для 3D-друку
  гайок/отворів додавайте зазор у слайсері або обирайте більший розмір.
