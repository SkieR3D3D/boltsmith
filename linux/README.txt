Boltsmith — Linux
=================
1. Розпакуйте папку Linux куди завгодно (напр. ~/Apps/Boltsmith).
2. У терміналі в цій папці:   bash install_linux.sh
   (завантажить CAD-ядро, додасть Boltsmith у меню програм і на робочий стіл з іконкою)
3. Далі — запуск з меню, або ./boltsmith.sh
Потрібен curl. Файли зберігаються в папку output поруч.

1. Unpack the Linux folder anywhere (e.g. ~/Apps/Boltsmith).
2. In a terminal in that folder:   bash install_linux.sh
   (downloads the CAD kernel, adds Boltsmith to the app menu and Desktop with its icon)
3. Then start it from the menu, or ./boltsmith.sh
Requires curl. Files are saved to the output folder next to it.
